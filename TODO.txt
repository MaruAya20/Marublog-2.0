三、Redis 集成详细规划
================================================================

详见下方 "Redis 学习与项目应用" 章节。

本项目 Redis 应用优先级：
  (1) Token 黑名单        ← 安全补丁，立竿见影
  (2) 验证码存 Redis      ← 去掉一条 DB 写入
  (3) API 限流            ← 防 SMTP 被刷
  (4) 浏览量 INCR + 批量写 ← 高频写优化
  (5) 热点缓存            ← 高频读优化

四、技术债 & 清理
================================================================

  - Settings.vue 壁纸上传逻辑较复杂，可封装独立 composable (useWallpaper.ts)
  - PostCard.vue 与 PostDetail.vue 存在大量重复代码（markdown 渲染、点赞收藏、评论组件等）
    → 可抽取公共组件 PostBody / CommentTree
  - 用户注销 deleteUser 里的 postRepository.findAll() 内存遍历 → 数据量大时要分页
  - 资源清理缺少"引用计数"机制（同一张图被两个文章引用时删一篇会误删）
    → 当前 Upload 模型设计是"每用必传"，不存在共享引用，暂时安全
